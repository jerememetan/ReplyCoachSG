# V7 v3 Light Local evaluation

V7 v3 keeps SEA-LION 3B as the source of the base reply and Qwen + DailyDialog
as the selector. The original V7 v2 used independent 50% phrase edits and
ranked only when it could generate three distinct variants. V7 v3 ranks whenever
at least one variant exists. It uses an expanded lexicon of 161 input phrases,
including forms adapted from Justin Peh and Wiktionary. We removed `you → chiu`
after inspecting its effects in a replay. V7 v3 prioritizes edits to different
phrases, tries two-phrase combinations, and ranks up to six variants alongside
the original. Particle forms such as `can lah`, `okay lor`, and `not sure sia`
can match within a reply. The generator, Qwen checkpoint, and Standard path are the same.
See the [method and lexicon sources](../v7_random_lexical.md).

## Replay on 60 revisited test conversations

The SEA-LION replies, conversation memory, Qwen checkpoint, and Gemma rubric
were fixed. Each configuration used one seeded draw per conversation. The V7 v3
replay verified 600 ratings from ten Gemma personas, including 230 fresh ratings
and 370 exact matches from prior runs.

| Light Local system | Appropriateness /5 | Naturalness /5 | Style fit /5 | Simulated would-send |
|---|---:|---:|---:|---:|
| SEA-LION 3B | 4.552 | 4.898 | 3.790 | 78.3% |
| Original V7 v2 | 4.603 | 4.908 | 3.947 | 81.2% |
| Intermediate standalone-only particle experiment | 4.627 | 4.940 | 3.967 | 83.5% |
| **V7 v3** | **4.655** | **4.948** | **4.393** | **86.5%** |

V7 v3 ranked variants in 56/60 cases and selected an edit in 37/60, up from
18/60 and 12/60 for the original V7 v2. Style fit rose by 0.447 out of 5
against V7 v2 (paired 95% bootstrap interval +0.242 to +0.683) and by 0.427
against the standalone-only experiment (+0.228 to +0.662). Simulated would-send
rose by 5.33 percentage points against V7 v2 (interval 0.0 to +11.0 points).
The comparisons against V7 v2 combine the dictionary and sampling changes.
V7 v3 changed seven of the 11 replies where SEA-LION's two styles were identical.

## Candidate-pool diagnostic on 50 development conversations

We compared the intermediate standalone-only pool with the same pool plus one human-reviewed Local reply
per case and an additional wording-only rewrite on eight cases. The same Qwen
checkpoint ranked the candidates, and ten Gemma personas rated the final pick in
each condition. All 500 rating cells per condition were covered, using 320 fresh
ratings across the two conditions.

| Metric | Intermediate pool | With added candidates | Difference | Paired 95% bootstrap interval |
|---|---:|---:|---:|---:|
| Appropriateness /5 | 4.564 | 4.634 | +0.070 | [0.000, +0.198] |
| Naturalness /5 | 4.972 | 4.964 | −0.008 | [−0.030, +0.006] |
| Style fit /5 | 4.360 | 4.456 | +0.096 | [−0.066, +0.272] |
| Simulated would-send | 84.6% | 87.8% | +3.2 pp | [+0.2, +8.2] pp |

Qwen changed its pick in 15/50 cases. Thirteen new winners were human-reviewed
replies and two were wording-only rewrites. The human-reviewed replies were
written for those exact conversations. This experiment measures what Qwen can
select when supplied with those replies. The live V7 v3 pipeline generates its
candidates from the SEA-LION reply and the lexicon. Gemma's simulated would-send
metric reflects model judgments.
