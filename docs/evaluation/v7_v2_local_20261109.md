# Isolated V7 v2 Local evaluation

V7 v2 Local scored **4.603 appropriateness, 4.908 naturalness, 3.947 style fit
and 81.2% simulated would-send**. Compared with plain SEA-LION Local, style fit
rose by 0.157 and would-send by 2.8 percentage points. The appropriateness
difference was +0.052, with a paired interval spanning zero. Compared with V7
v1, appropriateness rose by 0.163 and style fit fell by 0.928. The would-send
point estimate was 4.0 percentage points lower, with an interval spanning zero.

The final demo combines **V5 SEA-LION Standard** and **V7 v2 Light Local**.
This extension grades only Light Local on the same 60 previously inspected test conversations.
The original SEA-LION Local outputs, M2 memory, and conversation inputs were held fixed.
V7 v2 used one reproducible draw per conversation (seed 425 plus item ID).
The pinned Qwen + DailyDialog checkpoint ranked the original and three distinct wording
variants when available. The demo continues to sample wording randomly.

All 600 rating cells completed. 120 were fresh Gemma calls and 480 reused an exact
conversation, incoming message, style, reply and persona match from the 8 November run.
Gemma weights, rubric, response schema, options and personas matched that run.
Fresh grades ran on local Ollama 0.40.15. The 8 November run used
cluster Ollama 0.40.13. Simulated would-send is a persona judgment.
The results cover a revisited test set and one random draw per conversation.

and 0.048 s on the laptop.
