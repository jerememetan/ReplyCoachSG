# SEA-LION checkpoint handoff

Obtain the SEA-LION archive from the project team for the full demo.
Compare its hash to the SEA-LION entry in [SHA256SUMS](SHA256SUMS), then
extract it into the artifacts/model_handoff_v1 directory.

The extracted replycoach_sealion_repair25_v1 folder contains manifest.json,
infer.py, the base weights, tokenizer, adapters and source. See the
[demo setup](../../README.md#run-the-full-presentation-demo) for the other
required checkpoints.
