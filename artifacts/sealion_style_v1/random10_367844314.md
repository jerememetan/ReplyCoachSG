# SEA-LION: three additions and ten randomly drawn development examples

All experiments used personal account hm.teoh.2024 and the same exported SEA-LION repair25 source. No new generation was run for this sample.

1. Copy-aware candidate reranking: generate an N-best pool, reject candidates failing surface checks, and subtract a penalty for unnecessary exact English-draft copying. This changes inference, not weights.
2. Lexicon/grammar guidance: phrase preferences fitted only to745 existing paired training examples, plus narrow grammar candidate transformations. This changes inference, not weights; it does not simply append particles.
3. Copy-negative training: continue the Singlish LoRA for100 steps with ordinary reply CE, preferred-target CE, and a margin loss preferring existing Singlish targets over eligible exact English copies. A matched control has the same data/updates without the copy-margin term. Base and English adapter remain frozen.

Standalone1/2 below are the original v1 policies, including their conservative guard. Combined uses the100-step copy-loss adapter with contraction-corrected v2 guard and both inference additions. It is not an officially selected replacement. Both training arms retainstep0 under the validation guard. These are standard techniques applied and evaluated for this project, not a claim to invent the underlying algorithms.

Random sample: seed367844314;10 drawn uniformly without replacement from22 previously reviewed development cases. The source pool is a small reused review subset, not unseen test data. Ten assistant diagnostic controls were excluded. Outputs are verbatim. Guard passage/copy rate do not establish reply quality. English anchors themselves can contain errors.
