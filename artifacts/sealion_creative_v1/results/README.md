Positive examples allow genuinely different continuations: a proposed purpose for an unspecified call, texting first, accepting/declining an open invitation, suggesting another time, choosing a cheaper option, offering help or requesting necessary missing material. Known call purposes, ownership, locations, availability and completion are preserved. Bad examples include speaker reversals, contradictions, invented shared past agreements and claims to have assessed unseen material. Neutral/new ideas are not blanket-labelled bad. `target_audit.json` records each context's criterion and negative type.

The original model is a read-only comparison.
